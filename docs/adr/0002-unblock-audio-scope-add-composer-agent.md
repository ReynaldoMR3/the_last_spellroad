# Unblock audio/music scope for the vertical slice; add a Composer agent

Status: accepted

The GDD locked audio/music as explicitly out of scope for the vertical slice. The 2026-08-03 full playtest (issue #30) surfaced two real asks — a gameplay-relevant hit sound-cue ("we need sound to know when we are getting hit, so you can run away") and a new composer agent for original music — tracked as issue #81, with a same-day developer decision to log both without opening scope, deferred alongside the other atmosphere-wave decisions (#68/#69/#70) that #64 gates behind the mini-boss playtest (#30). The developer reversed that deferral 2026-08-04: audio is unblocked now, independent of both gates, because a gameplay-relevant audio signal reads as more foundational-feel than atmosphere polish and doesn't need to wait behind lore-density or potions-style decisions the way #68/#69/#70 do.

The scope taken on is the full sound design implied by "composer and audio effects," not just the one hit-cue: cast/impact/death SFX and ambient/footstep/UI audio alongside it. Coverage is deliberately reactive — audio gets made only for game elements that already exist, never speculatively ahead of unbuilt features — and audio tickets run in parallel with the rest of the backlog, never blocking non-audio work and never blocked by it. A new **Composer** agent joins the roster rather than folding music into an existing one: Lorena briefs the creative direction (mood, tempo, instrumentation) from her existing narrative/lore authority, Composer generates from that brief, and Heckler validates the result as a new lens in its six-persona panel — preserving the roster's standing rule that generation and validation never sit on the same agent. Composer's generation runs as a real Claude Code/Codex agent-dispatch session (spawned directly by Ana when her session supports it, a GitHub issue only as the fallback), not a raw API call and not local Ollama — `agent-crew`'s CrewAI/Ollama run already showed a small local model drifting on strict structured output, and asking a model to emit music notation directly is the same failure shape. SFX one-shots are sourced CC0-first (Kenney.nl, then OpenGameArt) by Tilesmith, extending its existing art-sourcing job rather than inventing a role for a task it's already equipped for. The whole pillar is tagged **stretch**, not floor: if the seven-week clock runs short, audio is the pre-agreed thing that slips, not combat, content, or narrative.

## Consequences

- The GDD's Screen Flow And Pause section's "audio/music... explicitly out of scope now" line is updated. The Options/Settings menu itself still doesn't ship — that stays out of scope; this ADR only reverses the audio/music generation lock, not the menu.
- `docs/agents/composer/` stands up with the same `AGENT.md`/`CONTEXT.md`/`log.md` contract shape as every other agent; `docs/agents/CONTEXT.md`'s index and the root `CLAUDE.md` roster table both gain a Composer row.
- Heckler's persona panel gains a music/audio critique lens; Lorena's job grows to include briefing Composer, not composing itself.
- Tilesmith's art-sourcing job grows to include SFX one-shots — same CC0-first search order and license-logging discipline already governing tile/sprite art, tracked in the same `art-sourcing-contract.md`.
- Ana's dispatch procedure gains a general rule, not specific to audio: spawn a sub-agent directly when the current session supports it, falling back to a GitHub issue only when it doesn't; prefer local Ollama subagents for token-cheap, quality-tolerant tasks, and reserve Claude Code/Codex dispatch for tasks — like Composer's notation generation — where a small local model's structured-output drift is a real risk.
- Backlog items 3.10 (Tilesmith SFX sourcing), 4.8 (Composer roster stand-up), and 4.9 (first Composer-authored track) track the actual build; none are floor-gating per the Minimal-Build Floor Vs. Stretch table's new Audio row.
- Issue #81 is closed by the PR implementing this ADR.
