# The Last Spellroad Art Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a local companion page that catalogs repository assets and turns scene-level art direction into validated, reviewable JSON proposals.

**Architecture:** Add a separate Vite Art Board entry while leaving the Phaser game unchanged. Pure TypeScript owns IDs, decisions, validation, and proposals. A deterministic Node scanner creates the catalogue. Vite development middleware persists validated briefs and review-only proposals.

**Tech Stack:** TypeScript, Vite 5, vanilla browser DOM, Vitest 2, Node.js built-ins, Phaser/Tiled JSON.

**Spec:** docs/superpowers/specs/2026-08-26-art-board-design.md

## Global Constraints

- Preserve Tiled JSON as the game map format; do not make the developer learn or use Tiled.
- Add no dependencies, local-model training, local model, or cloud-model runtime.
- Scan visual/audio assets under public/assets, retaining source/license evidence.
- Stable IDs derive from canonical path and optional sprite region; names/tags do not change them.
- Ignore generated cache in .art-board/cache; commit catalogue, overrides, and art briefs.
- A brief or proposal never applies a game-file change without explicit developer approval.
- Each task requires focused tests, typecheck, build or browser verification, and a commit.

## File Structure

| Path | Responsibility |
| --- | --- |
| art-board.html | Standalone Vite Art Board entry; never boots Phaser. |
| src/artBoard/domain.ts | Asset, brief, validation, and proposal contracts. |
| src/artBoard/catalog.ts | Catalogue/override merge, filtering, source status. |
| src/artBoard/boardState.ts | Pure reducer for level/entity decisions and brief export. |
| src/artBoard/proposal.ts | Pure brief-to-review-proposal compiler, with no writes. |
| src/artBoard/main.ts and styles.css | Three-panel local browser companion. |
| tools/art-board/generateCatalog.mjs | Deterministic repository asset scanner. |
| tools/art-board/devApi.ts | Development-only allow-listed persistence API. |
| art-direction/catalog.json | Committed asset metadata. |
| art-direction/overrides.json | Committed corrections to suggested tags/names/source facts. |
| art-direction/boards/*.json | Committed developer art briefs. |
| art-direction/proposals/ | Ignored review proposal payloads, with tracked .gitkeep. |

Each TypeScript module receives a neighboring test file. The scanner has tools/art-board/generateCatalog.test.mjs; the Vite API has tools/art-board/devApi.test.ts.
